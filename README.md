# 상품 등록 요청 툴

상품 등록 요청을 표로 정리하고, 고도몰 등록에 필요한 카테고리·썸네일·상세페이지 HTML까지 한곳에서 준비하는 웹 도구입니다.

엑셀과 메신저로 오가던 상품 요청 과정을 링크 하나로 공유하고, 등록 담당자가 값을 그대로 복사하거나 자동화 프로그램이 바로 읽어 갈 수 있는 형태로 만들어 줍니다.

## 무엇을 할 수 있나요

- **상품 목록 작성** — 표에 상품을 입력하거나 엑셀을 불러와 채우고, 저장하면 링크로 공유됩니다.
- **등록 정보 준비** — 소매몰·도매몰 카테고리, 원산지, 썸네일, 상세 이미지 주소를 상품별로 정리합니다.
- **상세페이지 HTML 생성** — 이미지 주소를 규칙에 맞춰 만들고, 실제로 열리는지 검사한 뒤 HTML을 복사할 수 있습니다.
- **등록 진행 확인** — 등록 완료 체크와 함께, 자동화 프로그램이 기록한 몰별 등록 상태(대기·진행중·완료·실패)를 확인합니다.
- **썸네일 자동 정리** — 등록 완료 3일 후 Supabase Storage 원본을 자동 삭제하고 상품에 정리 시각을 남깁니다.

## 구성

| 주소 | 용도 |
|---|---|
| `/` | 목록 찾기 |
| `/edit/` | 상품 목록 작성·수정 |
| `/view/` | 상품 보기·값 복사·등록 완료 체크 |
| `/settings/?tab=brands` | 브랜드 설정 (이름·코드·한글 검색명) |
| `/settings/?tab=categories` | 카테고리 설정 (소비자몰·도매몰 카테고리, 이미지 폴더) |

HTML/CSS/바닐라 JavaScript로 만들었고, 데이터는 Supabase에 저장합니다. 로그인 없이 링크로 공유하는 방식입니다.

## 상품 작성

상품 표는 읽기 전용이고, 행을 클릭하거나 **편집** 버튼을 누르면 상품 등록·수정 모달이 열립니다. 모달의 **기본 설정** 탭에서 상품명·브랜드·모델명·원산지·참고링크·비고와 몰별 등록 여부, 카테고리와 금액을 관리하고, **이미지 설정** 탭에서 썸네일·상세 이미지 주소·상세페이지 HTML을 준비합니다. 가격은 소비자몰 정가, 소비자몰 판매가(도매몰 정가), 도매몰 베이직·마스터 순서로 관리하며 스마트스토어 가격은 소비자몰 판매가와 항상 연동됩니다. 소비자몰 정가는 **직접 입력**을 켰을 때만 입력합니다.

표에서 체크·No.·브랜드·상품명 열은 왼쪽에 고정되고 모델명부터 오른쪽 열만 가로로 스크롤됩니다. 화면이 좁아지면 상품명만 고정하고 나머지 열은 스크롤 영역에서 그대로 볼 수 있습니다. 브랜드는 브랜드 선택 모달에서 이름·코드·한글 검색명·초성으로 찾을 수 있습니다.

상품명에 들어 있는 고도몰 HTML 태그(`<font …>` 등)는 저장·복사·내보내기 원문 그대로 보존하고, 목록 화면에서만 태그를 뺀 읽기용 텍스트로 표시합니다.

여러 행을 체크한 뒤 **일괄 설정**으로 카테고리·브랜드·원산지·등록 필요·가격·이미지 주소 생성 기본값을 한 번에 바꿀 수 있습니다. 내보내기·이미지 검사·목록 삭제는 **더보기**에 있습니다. 모달의 **상품 등록 / 수정 완료**는 목록 초안에만 반영하며, 상단 **저장하기**를 눌러야 공유됩니다. 사이드바의 각 리스트에는 `완료 상품 수 / 전체 상품 수`가 표시됩니다.

## 실행

Node.js와 Python 3가 있으면 별도 설치 없이 실행할 수 있습니다.

```bash
npm run build
npm start
```

`http://127.0.0.1:8942/`로 접속합니다.
