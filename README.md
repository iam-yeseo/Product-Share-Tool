# 상품 등록 요청 툴

자사몰 상품 등록 요청을 엑셀 대신 웹에서 주고받기 위한 사내 도구입니다.
HTML · CSS · JavaScript(바닐라)로만 만들어졌고, 데이터는 Supabase에 실시간으로 저장·동기화됩니다.

---

## 1. 화면 구성

### 상단 GNB
| 요소 | 설명 |
|---|---|
| **☰ 햄버거** | 사이드바(리스트 목록)를 접거나 폅니다. 넓은 화면은 접힘 상태가 기억되고, 좁은 화면은 덮어서 열립니다. |
| **편집자 / 등록자** | 화면 모드 전환. 화면이 바뀌는 게 아니라 **편집 가능 여부**만 달라집니다. |
| 동기화 표시 | `실시간 동기화 중`이면 다른 사람의 변경이 자동으로 반영됩니다. |
| `저장 안 됨` 배지 | 저장하지 않은 편집이 있을 때 표시됩니다. |
| **편집 완료 · 저장** | 편집자 모드에서만 보입니다. (`Ctrl/⌘ + S` 단축키 지원) |

### 사이드바
- 리스트가 **등록일 최신순**으로 나열됩니다.
- 검색창에서 **리스트 제목 · 작성자**로 필터링합니다.
- **+ 새 리스트 등록** 으로 새 리스트를 만듭니다.
- 오른쪽 배지는 `등록 완료 / 전체` 개수이며, 전부 완료되면 초록색이 됩니다.

---

## 2. 편집자 모드 (상품 등록을 요청하는 사람)

1. **+ 새 리스트 등록** → 이름 입력
2. **작성일 · 작성자**를 입력합니다. (둘 다 필수 — 비어 있으면 저장되지 않습니다)
3. **+ 행 추가** 로 상품을 추가하고 표를 채웁니다.
4. 다 쓰면 **편집 완료 · 저장** 을 누릅니다. → 이때 비로소 다른 사람에게 반영됩니다.

> 저장하지 않은 채 창을 닫거나 다른 리스트로 이동하면 **경고창**이 뜹니다.

### 체크로 여러 행 한 번에 다루기

편집자 화면의 **체크 열은 "행 선택"** 용입니다. 체크해도 등록 완료 상태는 **바뀌지 않습니다.**
(이미 등록 완료된 행은 회색 배경과 초록색 ✓ 표시로 구분됩니다.)

| 버튼 | 하는 일 |
|---|---|
| **+ 행 추가** | 맨 아래에 빈 행 하나 추가 |
| **행 복사** | 체크한 행을 **바로 아래에 복제**. 내용은 그대로, 등록 완료 상태는 물려받지 않습니다 |
| **행 삭제** | 체크한 행을 모두 삭제 (확인창 → 저장하면 확정) |

- 표 머리글의 체크박스로 **전체 선택 / 해제** 할 수 있습니다.
- 순번은 복사·삭제 후 자동으로 1번부터 다시 매겨집니다.

### 엑셀 불러오기

**[엑셀 불러오기]** 버튼으로 기존 "신제품 작업 리스트" xlsx 파일을 그대로 읽어 표를 채웁니다.

- 사내 표준 양식(`No. · 브랜드 · 품명 · 모델명 · 내용 · 이미지 · 링크 · 비고`)과,
  머리글이 2줄인 확장 양식(`품명 → 자사몰/스마트스토어`, `등록 여부`, `가격` 포함)을 모두 인식합니다.
- 열 제목이 조금 달라도 이름이 비슷하면 알아서 맞춥니다. (품명·상품명·제품명 / 등록 여부·등록 필요 등)
- 불러오기 전 **어느 열이 어디로 들어가는지, 몇 개 행이 잡혔는지** 확인 창이 뜹니다.
  - `지우고 새로 채우기` 또는 `아래에 이어 붙이기` 중 선택.
  - 작성일이 파일에 있으면 자동으로 채워집니다.
- 파일은 **브라우저 안에서만** 분석되며 서버로 업로드되지 않습니다.
- 값 표기는 자동으로 정리됩니다: 신제품→`신규 제품`, `O/X`→`필요/불필요`, 가격은 숫자만.
- 불러온 뒤에도 반드시 **편집 완료 · 저장**을 눌러야 실제로 저장됩니다.

> 엑셀 안에 박힌 이미지는 가져오지 않습니다(이미지 열은 아직 준비 중). 링크는 셀의 하이퍼링크도 함께 읽습니다.

### 열 너비 조절

- 각 열 머리글 **오른쪽 경계를 마우스로 드래그**하면 너비가 바뀝니다.
- 바뀐 너비는 브라우저에 기억되어 다음에 열어도 유지됩니다.
- 경계선을 **더블클릭**하면 모든 열이 기본 너비로 돌아갑니다.

### 새 행 기본값

**+ 행 추가**로 만든 빈 행에는 아래 값이 미리 채워집니다. ([js/state.js](js/state.js)의 `DEFAULT_CONTENT`·`DEFAULT_NEED`에서 변경)

- 내용 : **신규 제품**
- 등록 필요(소매몰·도매몰·네이버) : 모두 **필요**

### 표 항목
| 열 | 입력 방식 |
|---|---|
| 체크 | 편집자 화면에서는 **행 선택**(복사·삭제용), 등록자 화면에서는 **등록 완료 표시** |
| 순번 | 숫자를 직접 바꾸거나 ▲▼ 버튼으로 순서를 옮깁니다 (자동으로 1번부터 다시 매겨짐) |
| 브랜드 / 모델명 | 텍스트 |
| 상품명 | **자사몰 · 네이버** 2개 열 |
| 내용 | 신규 제품 / 기존 제품 / 기타 중 선택 |
| 이미지 사용 여부 | 텍스트 |
| 등록 필요 | **소매몰 · 도매몰 · 네이버** 3개 열, 각각 필요 / 불필요 선택 |
| 가격 | **소매몰 · 도매몰 · 네이버** 3개 열, 숫자만 입력되며 1,000단위 쉼표와 ₩ 표시 |
| 이미지 | 추후 지원 예정 (현재 비활성) |
| 참고 링크 | 텍스트 (`https://` 없이 주소만 넣어도 됩니다) |
| 비고 | 텍스트 |

---

## 3. 등록자 모드 (실제로 상품을 등록하는 사람)

- **체크 열만** 조작할 수 있고, 나머지는 보기 전용입니다.
- 체크하면 그 행이 **회색**으로 바뀌고 즉시 저장됩니다.
- 텍스트 칸마다 **복사** 버튼이 있어 값을 그대로 복사해 붙여넣을 수 있습니다.
  (가격은 쉼표 없는 숫자만 복사됩니다)
- 참고 링크는 **[바로가기]** 버튼으로 새 탭에서 열립니다.

---

## 4. 실행 방법

정적 파일이라 아무 웹 서버에나 올리면 됩니다.

```bash
npx -y http-server "/Users/callam4/Desktop/일해라/Web/상품 등록용 툴" -p 8942 -c-1
```

브라우저에서 `http://localhost:8942` 접속.
사내 공유 시에는 Netlify·Vercel·GitHub Pages 등에 폴더째 올리고 링크만 전달하면 됩니다.

## 5. 데이터 저장 (Supabase)

- 프로젝트: `product-registration-tool` (리전 ap-northeast-2 / 서울)
- 테이블: `product_lists`, `product_items`
- 접속 정보는 [js/supabaseClient.js](js/supabaseClient.js) 상단 두 줄에만 있습니다.
- **로그인 없이 링크만으로 접근**하는 구조라 RLS 정책은 anon 전체 허용입니다.
  링크를 아는 사람은 누구나 읽고 쓸 수 있으므로 **링크 공유 범위에 주의**하세요.
  나중에 로그인을 붙이고 싶으면 정책을 `authenticated` 전용으로 바꾸면 됩니다.
- 프론트엔드에는 publishable key만 들어갑니다. **service_role key는 절대 넣지 마세요.**

## 6. 파일 구조

```
index.html              화면 구조(GNB · 사이드바 · 표 · 불러오기 창)
css/style.css           전체 스타일
js/supabaseClient.js    Supabase 접속 정보
js/utils.js             날짜·금액·복사 등 공통 함수
js/state.js             화면 상태 / 초안 관리 / 새 행 기본값
js/api.js               Supabase 읽기·쓰기
js/xlsxImport.js        엑셀(xlsx) 분석 → 표 행으로 변환
js/ui.js                사이드바·표 그리기 / 열 너비 관리
js/app.js               이벤트 연결, 실시간 동기화, 불러오기·리사이즈·사이드바
```

> 엑셀 파싱은 SheetJS(`cdn.sheetjs.com`)를 사용합니다. 인터넷이 되는 환경에서 열어야 불러오기가 동작합니다.
