## 운영 Supabase

사용자가 승인한 범위로 마이그레이션을 적용했고 보안 advisor 경고는 0건이었다.

별도 테스트 목록에서 실제 anon 저장 함수, 썸네일 업로드와 공개 이미지 로딩, 저장 후 새로고침, DOM JSON의 ready/saved 상태, 코드/HTML/검사 결과 재조회를 확인했다. view에서 완료 체크 후 edit에서 다시 저장해도 완료 시각이 유지됐다. 잘못된 상품 값을 보낸 저장은 목록 수정까지 트랜잭션 전체가 롤백됨을 anon 역할로 확인했다.

테스트 상품과 목록은 검증 후 제거했다. 덮어쓰기/삭제 권한을 추가하지 않는 정책에 따라 68바이트 PNG 검증 원본 1개는 Storage에 남아 있다. 기존 상품 정보는 수정하지 않았다.

카테고리 초기값은 소매 144개, 도매 135개, 이미지 폴더 21개. 신규 Storage 정책은 지정 버킷·기존 목록 경로의 INSERT만 허용하며 파일 형식/6MB 제한을 확인했다.

## 적용 범위

기존 GitHub Pages는 main 브랜치를 배포한다. 이 기능 브랜치의 프론트엔드는 PR 병합 전까지 운영 도메인에 배포되지 않는다. 운영 DB의 추가 필드와 함수는 기존 프론트엔드와 호환된다.

- `npm run build`, `npm test` 14개, `npm run check`, `git diff --check` 통과. 브랜드 매칭(대소문자·공백·기호 무시), 중복·형식 검증, 이전 설정 형식 호환, 내보내기의 `brandCode`/`brandRegistered`, 임시 UI 플래그 제외, `image_usage` 제거, 엑셀 브랜드 매칭 통계를 추가로 검사.
- 분리된 QA 미리보기(Chromium): 열 19개이며 '이미지 사용 여부' 머리글 없음. 기본 편집에서 이미지 열 너비 0, 자동화 편집으로 바꾸면 100px로 복귀. 브랜드 선택 → 직접 입력 전환 시 입력칸에 자동 포커스, **목록** 버튼으로 복귀 시 일치하는 이름은 선택되고 없는 이름은 비워짐. 행 추가 시 브랜드 선택에 포커스.
- 불러오기 확인 창에 "자동 선택 2개 · 직접 입력 1개 · 비어 있음 1개" 표시. 적용 후 `tilta`→TILTA 선택, `Electro Voice`→Electro-Voice 선택, 미등록 이름은 직접 입력칸으로 표시. 저장 후 DB 문자열과 DOM JSON의 `brandCode`(165/189)·`brandRegistered` 확인. SheetJS CDN이 차단된 환경이라 파일 파싱 자체는 단위 검사 범위 밖이며, 파싱 결과를 앱의 확인 창 경로로 넣어 검증.
- 보기 페이지: 미등록 브랜드에 **직접 입력** 표시, 이미지 열 유지.
- 설정 > 브랜드: 84개 표시, 검색, `tilta` 중복 추가 거부, 추가·이름 수정·사용 중지·삭제 후 저장. 사용 중지한 브랜드는 편집 선택지에서 숨겨지고, 이름이 바뀐 브랜드를 쓰던 상품은 직접 입력으로 표시됨. 390px에서 가로 넘침 없음.
