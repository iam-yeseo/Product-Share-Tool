## 운영 Supabase

사용자가 승인한 범위로 마이그레이션을 적용했고 보안 advisor 경고는 0건이었다.

별도 테스트 목록에서 실제 anon 저장 함수, 썸네일 업로드와 공개 이미지 로딩, 저장 후 새로고침, DOM JSON의 ready/saved 상태, 코드/HTML/검사 결과 재조회를 확인했다. view에서 완료 체크 후 edit에서 다시 저장해도 완료 시각이 유지됐다. 잘못된 상품 값을 보낸 저장은 목록 수정까지 트랜잭션 전체가 롤백됨을 anon 역할로 확인했다.

테스트 상품과 목록은 검증 후 제거했다. 덮어쓰기/삭제 권한을 추가하지 않는 정책에 따라 68바이트 PNG 검증 원본 1개는 Storage에 남아 있다. 기존 상품 정보는 수정하지 않았다.

카테고리 초기값은 소매 144개, 도매 135개, 이미지 폴더 21개. 신규 Storage 정책은 지정 버킷·기존 목록 경로의 INSERT만 허용하며 파일 형식/6MB 제한을 확인했다.

## 적용 범위

기존 GitHub Pages는 main 브랜치를 배포한다. 이 기능 브랜치의 프론트엔드는 PR 병합 전까지 운영 도메인에 배포되지 않는다. 운영 DB의 추가 필드와 함수는 기존 프론트엔드와 호환된다.
