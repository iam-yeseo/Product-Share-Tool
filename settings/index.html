상품 등록 설정

브랜드 목록, 몰별 카테고리, 상세 이미지 폴더를 관리합니다. 저장한 설정은 모든 사용자에게 공유됩니다.

브랜드

편집 페이지의 브랜드 칸에서 고를 수 있는 목록입니다. 목록에 없는 브랜드는 편집 페이지에서 직접 입력으로 넣을 수 있고, 엑셀을 불러올 때 이름이 같은 브랜드(대소문자·공백 무시)는 자동으로 선택됩니다.

브랜드 추가

이름을 바꾸거나 삭제해도 이미 저장된 상품의 브랜드 문자열은 바뀌지 않습니다. 목록과 맞지 않게 된 상품은 편집 페이지에서 직접 입력으로 표시됩니다.
